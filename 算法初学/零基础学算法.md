# 前言

首先就是，市面上的大多数算法竞赛，考来考去就是考的数据结构与算法嘛，无非就是难度的差别。

个人观点的排名，由获奖难度和含金量综合考虑
> 这里要说明的是，有含金量的比赛不一定加保研分或综测分，这个主要要看学校的加分细致

| 级别  | 比赛                            |
| --- | ----------------------------- |
| TO  | ICPC国际大学生程序设计大赛 CCPC中国大学生程序设计 |
| T1  | ICPC，CCPC邀请赛，省赛。百度之星          |
| T2  | 马蹄杯，蓝桥杯，天梯团体赛                 |
| T3  | 计算机挑战赛 ，传智杯                   |
|     | 等等                            |


> [!important] 注意
> 没有加入ACM实验室的同学，ICPC和CCPC的相关赛事的观点可以不用看


一般来讲：
- 认真学一年，T2和T3是拿奖没问题的，T0和T1要看造化🙂
- 2年，努力点T1应该可以拿奖，T0也是看造化

普通学生(大学之前没有信息学竞赛基础的)如果是功利地去打算法竞赛的话，感觉最多打2年就结束了，然后能不能拿T0得看造化，T1看努力程度吧。

如果是喜欢，当成游戏去打的话，这应该是最好的心态了。
最近这一两年，ICPC区域赛和CCPC国赛拿牌的队伍很多都有OIer(大学之前有信息学竞赛基础的)。
当然普通人也能拿牌，只不过确实要花费大量的时间，如果是功利心但训练又不努力的话，几乎不可能拿奖。

但ICPC和CCPC的邀请赛和省赛难度相对区域赛小很多，努力训练是可以拿奖的


> [!NOTE] 这里提醒一点
> 关于ICPC和CCPC的赛事需要加入ACM实验室才能参加，
  天梯团体赛也是这样。
  其他算法赛事不限制


# 怎么学

## 教学资料

**视频个人推荐：**
- [左程云的个人空间-左程云个人主页-哔哩哔哩视频](https://space.bilibili.com/8888480?spm_id_from=333.788.upinfo.head.click) 
	- 讲得非常细，但是时长不友好，一个视频一般2h(包含代码讲解和配套的题目)，教学代码是java(应该看得懂不难，基础语法和C++类似)
	- 这个老师回复也挺快的，如果你不确定要学到哪，就在评论区问一下，**xxx比赛拿xx奖要学到哪里，然后就会有个参考。**
- [董晓算法的个人空间-董晓算法个人主页-哔哩哔哩视频](https://space.bilibili.com/517494241?spm_id_from=333.337.0.0)
	- 讲得也很好，基础算法时长在10分钟左右，难一点的在30分钟左右，和左程云的风格有些区别。

2个老师都讲得很好，但是风格不一样，建议配合着来看；

网站推荐：
- 教学网站：
	- [OI Wiki - OI Wiki](https://oi-wiki.org/)
		- 这个网站收集的算法很全，适合打印成纸张当作比赛用的模板。
		- 适合算法知识查漏补缺，但我不建议把这个网站当作学习的主战场，还是看上面的视频要好点，因为上面的2个老师视频讲到的算法加起来应该是覆盖到ICPC区域赛金牌的范畴了，跟着视频教程学要好得多
		
	- [代码随想录-全网最全算法数据结构刷题学习路线|图文+视频教程|免费开源](https://programmercarl.com/)
		- 这个可能更适合找工作面试
- 刷题：
	- [Codeforces](https://codeforces.com/) **(推荐主力)**
		- 这个是俄罗斯那边的，属于很主流的算法刷题平台，上面的题目和比赛很适合思维训练，如果有冲击XCPC的想法，推荐尽早熟悉使用
		
	- [AtCoder](https://atcoder.jp/)
		- 这个是日本那边的，适合平时打打比赛，**一般是打AtCoder Beginner Contest**，俗称ABC，初学者比较友好。
		
	- [首页 - 洛谷 | 计算机科学教育新生态](https://www.luogu.com.cn/) **(推荐主力)**
		- 国内主流的算法平台，题目质量不错，也适合初学者刷
		
	- [牛客竞赛OJ_ACM/NOI/CSP/CCPC/ICPC_信息学编程算法训练平台](https://ac.nowcoder.com/acm/contest/vip-index?topCategoryFilter=13)
		- 跟上面的差不多
		
	- [蓝桥杯大赛 — 全国大学生TMT行业赛事](https://dasai.lanqiao.cn/) 
		- 蓝桥杯的官网，适合蓝桥杯备赛
	- [码蹄集](https://www.matiji.net/exam/)
		- 马蹄杯和百度之星的，适合他们备赛
		
	- [QOJ - QOJ.ac](https://qoj.ac/)
		- 收录了大多数的XCPC比赛


这些算法刷题网站怎么用？
- 个人倾向于 洛谷 和 codeforces 2个网站为主力；
- 然后 牛客 和 codeforces 以及 AtCoder 的线上算法赛平时也可以打一下，codeforces的时间一般是在晚上 22:35 - 01:05 , 这个时间节点比较阴间，怎么打就大家自行琢磨，大然也可以询问银学长。牛客的比赛一般是在 19:00开始，具体时间需要在牛客网站查看; AtCoder的时间和牛客差别不大。
- 如果不打XCPC，一般就在 牛客 和 AtCoder 上打打比赛就差不多了

对于对XCPC有想法，并且加入了ACM实验室的同学：
- 尽早打 codeforces 上面的比赛以及其他网站的比赛，对思维很有帮助，前4道或3道一般都是思维，没有什么算法。
- 尽早形成自己的训练节奏，自己训练自己是很重要的。
- XCPC比较难，要有健康的心态

任何一场比赛打完后记得补题，按难度顺序，补自己没做出来的1~2道，或者更多。借助题解或AI。
