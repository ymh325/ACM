> [!NOTE] 时间复杂度：$O(n)$

> [!question] 问题
> 给一个数 $n\;(n \le 1\times 10^6)$  ，输出 $1\sim n$每个数的约束个数


> [!example] 约束个数定理
> 若 $n = \prod_{i=1}^{s} p_i^{\alpha_i}$，则 $d(n) = \prod_{i=1}^{s} (\alpha_i + 1)$。

证明：$p_i^{\alpha_i}$ 的约数有 $p_i^0, p_i^1, \cdots, p_i^{\alpha_i}$ 共 $(\alpha_i + 1)$ 个，
根据乘法原理，$d(n) = \prod_{i=1}^{s}(\alpha_i + 1)$。


# 筛法求约数个数

前置知识：
- [[线性筛素数]]

**令 $a[i]$ 为 $i$ 的最小质因数的幂**
若 $i$ 是质数，$a[i] = 1, d[i] = 2$。
在线性筛中，每个合数 $m$ 都是被**最小的质因子**筛掉的。
设 $p_j$ 是 $m$ 的最小质因子，则 $m$ 通过 $m = p_j \times i$ 筛掉。

1. 若 $i$ 能被 $p_j$ 整除，则 $p_j$ 一定是 $i$ 的最小质因子。
	$a[m] = a[i] + 1;$
	$d[i] = (a[i] + 1) \times \cdots, d[m] = (a[m] + 1) \times \cdots$

2. 若 $i$ 不能被 $p_j$ 整除，则 $i$ 不包含质因子 $p_j$。
	$a[m] = 1, d[m] = d[i] \times (1 + 1)$


> [!example] 代码

```cpp
#define int long long
const int N = 1e5+5;
vector<int> prim;
vector<int> vis(N,0);
vector<int> d(N,0);

void get_d(int n){
	d[1] = 1;
	for(int i=2;i<=n;i++){
		if(!vis[i]){
			prim.push_back(i);
			a[i] = 1,d[i] = 2;
		}
		for(int j= 0;j<prim.size();j++){
			if(i*prim[j] > n){
				break;
			}
			int m = i * prim[j];
			vis[m] = 1;
			if(i%m == 0){
				a[m] = a[i] + 1;
				d[m] = d[i] / a[m] * (a[m]+1);
				break;
			}
			else {
				a[m] = 1;
				d[m] = (1 + 1) * d[i]; 
			}
		}
	}
}
```
