# 欧拉函数

## 定义

> [!NOTE] 定义
> $1 \sim n$ 中与 $n$ 互质的数的个数称为欧拉函数，记为 $\varphi(n)$

## 性质

1. 若 $p$ 是质数，则 $\varphi(p) = p-1$
2. 若 $p$ 是质数，则 $\varphi(p^k) = (p-1)p^{k-1}$
3. 积性函数：若 $gcd(m,n) = 1$ ，则 $\varphi(mn) = \varphi(m)\varphi(n)$

## 计算公式

由[[质因数分解定理|唯一分解定理]] ，$n = \prod_{i=1}^{s} p_i^{\alpha_i} = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_s^{\alpha_s}$ ，
可以推导出：
$$
\begin{aligned} \varphi(n) &= \prod_{i=1}^{s} \varphi\left(p_i^{\alpha_i}\right) \\ &= \prod_{i=1}^{s} p_i^{\alpha_i-1}(p_i - 1) \\ &= \prod_{i=1}^{s} p_i^{\alpha_i}\left(1 - \frac{1}{p_i}\right) \\ &= \prod_{i=1}^{s} p_i^{\alpha_i} \times \prod_{i=1}^{s}\left(1 - \frac{1}{p_i}\right) \\ &= n \times \prod_{i=1}^{s} \frac{p_i-1}{p_i} \\ &= n \times \frac{p_1-1}{p_1} \times \frac{p_2-1}{p_2} \times \cdots \times \frac{p_s-1}{p_s} \end{aligned}
$$
故，欧拉函数仅有 $n$ 和 质因子决定，与次数无关。
例：$\varphi(12) = 12 \times \frac{2-1}{2} \times \frac{3-1}{3} = 4$ 

# 试除法求欧拉函数

> [!NOTE] 时间复杂度：$O(\sqrt{n})$

前置知识：
- [[质因数分解定理#试除法求解]]

在用试除法求质因数分解的过程中，可以顺便计算：
$$
\begin{aligned} 
\varphi(n) &= n \times \frac{p_1-1}{p_1} \times \frac{p_2-1}{p_2} \times \cdots \times \frac{p_s-1}{p_s} 
\end{aligned}
$$

> [!example] 代码

```cpp
int phi(int n){
	int res = n;
	for(int i=2;i*i<=n;i++){
		if(n%i==0){
			res = res / i * (i-1);
			while(n%i==0)n/=i;
		}
	}
	if(n>1)res = res/n*(n-1);
	return res;
}
```

# 筛法求欧拉函数

> [!NOTE] 时间复杂度：$O(n)$
> 可在 $O(n)$ 下， 求得 $1\sim n$ 的欧拉函数


前置知识
- [[线性筛素数]]

列出公式：
$$
\begin{aligned}
\varphi(n) &= n \times \frac{p_1-1}{p_1} \times \frac{p_2-1}{p_2} \times \cdots \times \frac{p_s-1}{p_s} 
\\ &= n \times \prod_{i=1}^{s} \frac{p_i-1}{p_i} 
\end{aligned}

$$

若 $i$ 是质数， $phi[i] = i-1$ 。
在线性筛中，每个合数 $m$ 都是被 **最小的质因子** 筛掉的。
设 $p_j$ 是 $m$ 最小质因子，则 $m$ 通过 $m= p_j \times i$ 筛掉的。

1. 若 $i$ 能被 $p_j$ 整除，**则 $i$ 包含了 $m$ 的所有质因子**。
$$
\begin{aligned}
\varphi(m) &= m \times \prod_{k=1}^{s} \frac{p_k-1}{p_k} 
\\ &= p_j \times i \times \prod_{k=1}^{s} \frac{p_k-1}{p_k}
\\ &= p_j \times \varphi(i)
\end{aligned}
$$
2. 若 $i$ 不能被 $p_j$ 整除，则 $i$ 和 $p_j$ 是互质的，根据 [[欧拉函数#性质|性质3]] 可得：
	$$
	\begin{aligned}
	\varphi(m) &= \varphi(p_j\times i) 
	\\ &= \varphi(p_i) \times \varphi(i)
	\\ &= (p_j-1)\times\varphi(i)
	\end{aligned}
	$$


> [!example] 代码

```cpp
#define int long long
const int N = 1e5+5;
vector<int> prim;
vector<int> vis(N,0);
int phi[N];

void get_phi(){
	phi[1] = 1;
	for(int i=2;i<=n;i++){
		if(!vis[i]){
			prim.push_back(i);
			phi[i] = i-1;
		}
		for(int j = 0;j < prim.size();j++){
			if(j*prim[i]>n){
				break;
			}
			int m = i * prim[j]; 
			prim[m] = 1;
			if(i % prim[j] == 0){
				phi[m] = prim[j] * phi[i]; 
				break;
			}else {
				phi[m] = (prim[j]-1) * (phi[i]);
			}
		}
	}
}
```
