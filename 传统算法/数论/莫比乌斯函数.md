# 莫比乌斯函数

## 定义

由[[质因数分解定理|唯一分解定理]]，任意大于 $1$ 的正整数 $n$ 都可以唯一表示为：

$$
n=\prod_{i=1}^{s}p_i^{\alpha_i}
=p_1^{\alpha_1}p_2^{\alpha_2}\cdots p_s^{\alpha_s},
$$

其中 $p_1,p_2,\ldots,p_s$ 是 $n$ 的 $s$ 个不同质因子。

> [!NOTE] 定义
> 莫比乌斯函数 $\mu(n)$ 定义为：
> $$
> \mu(n)=
> \begin{cases}
> 1, & n=1,\\
> 0, & n \text{ 含有平方质因子},\\
> (-1)^s, & n \text{ 含有 }s\text{ 个不同质因子}.
> \end{cases}
> $$

换句话说：

- 当 $n=1$ 时，$\mu(n)=1$；
- 当某个质因子的次数 $\alpha_i\ge 2$ 时，$\mu(n)=0$；
- 当所有 $\alpha_i=1$ 时，若不同质因子的个数为偶数，则 $\mu(n)=1$，否则 $\mu(n)=-1$。

例如：

$$
\begin{aligned}
&\mu(1)=\mu(6)=\mu(10)=\mu(15)=1,\\
&\mu(4)=\mu(8)=\mu(9)=\mu(12)=0,\\
&\mu(2)=\mu(3)=\mu(5)=\mu(7)=\mu(30)=-1.
\end{aligned}
$$

# 线性筛求莫比乌斯函数

> [!NOTE] 时间复杂度：$O(n)$
> 可在线性时间内求出 $1\sim n$ 的所有莫比乌斯函数值。

在线性筛中，每个合数 $m$ 都只会被它的**最小质因子**筛掉。

设当前枚举到 $i$，内层枚举质数 $p$，令：

$$
m=i\times p.
$$

根据 $p$ 是否已经是 $i$ 的质因子，分为两种情况。

## $p\mid i$

此时 $i$ 已经含有质因子 $p$，所以 $m=i\times p$ 至少含有 $p^2$，即 $m$ 含有平方质因子：

$$
\mu(m)=0.
$$

在线性筛中，遇到这种情况还要立即 `break`，以保证每个合数只被其最小质因子筛掉。

## $p\nmid i$

此时 $m$ 比 $i$ 多了一个不同的质因子 $p$。

- 若 $\mu(i)=1$，则不同质因子的个数由偶数变为奇数，$\mu(m)=-1$；
- 若 $\mu(i)=-1$，则不同质因子的个数由奇数变为偶数，$\mu(m)=1$；
- 若 $\mu(i)=0$，则 $i$ 已含有平方质因子，$m$ 仍含有平方质因子，$\mu(m)=0$。

因此三种情况可以统一写成：

$$
\mu(m)=-\mu(i).
$$

若 $i$ 本身是质数，则它只有一个不同质因子，所以：

$$
\mu(i)=-1.
$$

> [!example] 代码

```cpp
const int N = 1e6 + 10;

vector<int> prim;
bool vis[N];
int mu[N];

void get_mu(int n){
	mu[1] = 1;
	for(int i=2;i<=n;i++){
		if(!vis[i]){
			prim.push_back(i);
			mu[i] = -1;
		}
		for(int p : prim){
			if(1LL*i*p>n)break;
			int m = i*p;
			vis[m] = true;
			if(i%p==0){
				mu[m] = 0;
				break;
			}else{
				mu[m] = -mu[i];
			}
		}
	}
}
```
