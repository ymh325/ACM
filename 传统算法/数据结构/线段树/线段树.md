# 线段树

> [!done] 简介
> 基于二分思想的二叉树，用来维护区间信息（区间和，区间最值，区间GCD等）


**可以在  $O(logn)$ 的时间复杂度内执行 `区间修改` 和 `区间查询`**

线段树中每个 <font color="#ff0000">叶子结点</font> 存储元素本身，<font color="#ff0000">非叶子结点</font> 存储区间元素的统计值

---


> [!example] 以维护**区间和**为例
## 1.节点数组  `tr[]`：

​	创建结构体，结构体包含三个变量：$l，r，sum$，

​	$l，r$  存区间的左右端点，$sum$ 存区间和


```cpp
const int N = 1e5; // 区间长度
struct {
	int l,r,sum;
}tr[N*4];
```


> [!warning] Title
> 不离散化的话，N最多只能到 `1e6`


## 2.递归建树$O(n)$

- 父节点编号为 $p$
- 左孩子编号为 $2 * p$ ，右孩子编号为  $2 * p+1$

```cpp
#define lc p<<1
#definr rc p<<1|1
const int N = 50005
int n,w[N];
struct{
    int l,r,sum;
}tr[N*4];

void build(int p,int l,int r){
    tr[p]={l,r,w[l]};
    if(l==r)return;
    int m = l+r>>1;
    build(lc,l,m);
    build(rc,m+1,r);
    tr[p].sum=tr[lc].sum+tr[rc].sum;
}
```



## 3.点修改$O(logn)$

​	例如，对 $x = 7$ 位置上的数加 $5$

​	从根节点进入，<font color="#ff0000">递归</font>找到叶子节点`[x,x]`，把该节点的值增加 $k$ 。然后从下往上更新其祖先节点上的统计值。

```cpp
void update(int p,int x,int k){
    if(tr[p].l==x&&tr[p].r==x){
        tr[p].sum+=k;
        return ;
    }
    int m=tr[p].l+tr[p].r>>1;
    //if(x<=m)update(lc,x,k);
    //else update(rc,x,k);
    update(x<=m? lc:rc,x,k);
    tr[p].sum=tr[lc].sum+tr[rc].sum;
}
```


> [!question] 为什么点修改是 $O(log{n})$呢？
> 每一次往下都是对当前区间的对半分，要么去左半边，要么去右半边
> 那这是不是就类似于**二分查找** ($O(log{n})$)了，只不过是表现在一棵树上


## 4.区间查询$O(logn)$

​	<font color="#ff0000">拆分与拼凑</font>的思想。例如，查询区间 `[4,9]` 可以拆分成 `[4,5]` ，`[6,8]` 和 `[9,9]` ，通过合并这三个区间的答案求得查询答案。

​从根节点进入，递归执行以下过程：
1. 若查询区间 `[x,y]` 完全覆盖当前节点区间，则立
​	   即回溯，并返回该节点的 $sum$ 值。
2. 若左子节点与 `[x,y]` 有重叠，则递归访问左子树：
3. 若右子节点与 `[x,y]` 有重叠，则递归访问右子树。

```cpp
int query(int p,int x,int y){
    if(x<=tr[p].l&&tr[p].r<=y){
        return tr[p].sum; // 覆盖则返回
    }
    // pushdown(p) 要记得清除懒标记
    int m = tr[p].l+tr[p].r>>1; // 不覆盖则裂开
    int sum = 0;
    if(x <= m)sum += query(lc,x,y);
    if(y > m)sum += query(rc,x,y);
    return sum;
}
```



## 5.区间修改$O(logn)$

​	例如，对区间 `[4,9]` 内的每个数加上 $5$。如果修改区间x所覆盖的每个吐子节点，时间将是 $O(n)$ 的。

​	我们做<font color="#ff0000">懒惰修改</font>，当 `[x,y]` <font color="#ff0000">完全覆盖</font>节点区间 `[a,b]`时，先修改该区间的 `sum`值，再打上一个“懒标记"，然后立即返回。等下次需要时，再下传“懒标记”。这样，可以把每次修改和查询的时间都控制到 $O(nlogn)$

```cpp
// 向上更新
void pushup(int p){
    tr[p].sum = tr[lc].sum + tr[rc].sum;
}
// 向下更新
void pushdown(int p){
    if(tr[p].add){
        tr[lc].add += tr[p].add;
        tr[rc].add += tr[p].add;
        tr[lc].sum += tr[p].add * (tr[lc].r - tr[lc].l + 1);
        tr[rc].sum += tr[p].add * (tr[rc].r - tr[rc].l + 1);
        tr[p].add = 0;
    }
}
void update(int p,int x,int y,int k){
    if(x <= tr[p].l && tr[p].r <= y){ // 覆盖则修改
        tr[p].sum += k * (tr[p].r - tr[p].l + 1);
        tr[p].add += k;
        return;
    }
    int m = (tr[p].l + tr[p].r) >> 1; // 不覆盖则裂开
    pushdown(p);
    if(x <= m) update(lc,x,y,k);
    if(y > m) update(rc,x,y,k);
    pushup(p);
}
```

# 线段树常见方法一览

`void up(i..)`：根据子范围的查询信息，把父范围的查询信息更新正确

`void down(i..)`：父范围的懒信息，往下只下发一层，给左范围、右范围，然后父范围的懒信息清空

`void lazy(i..)`：一段范围的整体被当前更新任务的范围全覆盖时，懒信息如何修改

`void build(l，r，i)`：建树

`void update(jobl，jobr，jobv，l，r，i)`：范围上数值的重置任务

`void add(jobl，jobr，jobv，l，r，i)`：范围上数值的增加任务

`int query(jobl，jobr，l，r，i)`：范围上的信息查询任务
