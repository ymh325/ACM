# 并查集

> 一种树形的数据结构


**有两种操作**：
- **合并**：将两个子集合并成一个集合
- **查找**：确定某个元素处在哪个集合

## 初始化

- `fa[x]` 存节点 `x` 的父节点


> [!example] `fa[]` 初始化：每个节点是一个集合，每个节点的父亲是它自己
```cpp
for(int i=1;i<=n;i++)fa[i]=i;
```

## 查找

> 查找元素所在集合的根

### 一般查找
- 如果父节点等于自己，则找到了根并返回
- 如果还没找到根，则继续递归查找

```cpp
int find(int x){
    if(fa[x]==x)return x;
    return find(fa[x]);
}
```

### 带路径压缩的查找
> 通常用这个

- 在返回的路上，顺带修改各节点的父节点为根，也就是让所有子节点指向最开头的根节点

```cpp
int find(int x){
    if(fa[x]==x)return x;
    return fa[x]=find(fa[x]);
}
```

## 合并

> 把一个集合的根指向另一个集合的根

```cpp
void merge(int x,int y){
    fa[find(x)]=find(y);
}
```


## 是否同集合


> [!example] 代码
```cpp
int isSame(int x,int y){
	return find(x) == find(y);
}

```

# 带权并查集

前置知识：
- [[#并查集]]

> [!NOTE] 
> - 普通并查集只维护 "两个点是否连通"；
> - 带权并查集还维护同一集合中任意两点之间的**相对关系**。

## 思想

把每个集合看成一棵树，**边权表示当前节点与父节点的关系**。

这里用一维坐标模型说明：

概念引入：
- `fa[x]`：`x` 的父节点
- `dis[x]`：`x` 到父节点的距离
	-  `dis[x]` > 0 ，`x` 在父节点的右侧
	-  `dis[x]` < 0 ，`x` 在父节点的左侧

```cpp
for (int i = 0; i <= n; i++) {
    fa[i] = i;
    dis[i] = 0;
}
```

> i 最好从 0 开始初始化,某些题目,i == 0 是由含义的 
## 操作

### `int find(x)`

寻找 `x` 所在集合的头，同时修正 `dist[x]` 的值；
路径压缩之前 `x` 的父为 `t` ，路径压缩之后，`dist[x] += dist[t]` 

```cpp
int find(int x){
	if(fa[x] == x)return x;
	fa[x] = find(fa[x]);
	dist[x] += dist[fa[x]];
	return fa[x];
}
```

### `void union(l,r,v)`

`l` , `r` 属于 2 个集合，并且 `l` 到 `r` 的距离为 `v` ，合并两个集合

```cpp
void unio(int l,int r,int v){
	int lf = find(l);
	int rf = find(r);
	
	fa[lf] = rf;
	dist[lf] = dist[r] - dist[l] + v;
}
```

### `int query(l,r)`

查询 `l` 和 `r` 之间的距离关系

```cpp
int query(int l,int r){
	if(find(l) != find(r))return 0;
	
	return dist[l] - dist[r];
	
}

```

### 异或关系

`dis[r] ^ dis[l] ^ v`

| 关系       | 路径复合     | 逆运算      | 单位元 | 同集合查询                     |
| -------- | -------- | -------- | --- | ------------------------- |
| 差值       | `+`      | 取负       | `0` | `dis[x] - dis[y]`         |
| 倍数       | `*`      | 取倒数      | `1` | `weight[x] / weight[y]`   |
| 模 $k$ 关系 | 模 $k$ 加法 | 模 $k$ 取负 | `0` | `(dis[x] - dis[y]) mod k` |
| 异或       | `^`      | 自身       | `0` | `xr[x] ^ xr[y]`           |

做题时依次确定：

1. `weight[x]` 表示 `x` 到父节点，还是父节点到 `x`；
2. 关系如何沿路径复合；
3. 两个根按哪个方向合并，以及新根边权的公式；
4. 已连通时如何查询、如何判断新约束矛盾；
5. 是否需要额外维护集合大小、虚拟节点等信息。
