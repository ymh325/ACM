# 拓扑排序

## 定义

> [!NOTE]
> 给定一张**有向无环图（DAG）**，如果一个顶点序列 $A$ 满足：对于图中的每条有向边 $(x,y)$，$x$ 在 $A$ 中都出现在 $y$ 之前，那么称 $A$ 是该图的一个拓扑序。
> 

例如，`{2,3,5,1,7,4,6}` 和 `{3,2,1,5,7,6,4}` 都可能是同一张图的合法拓扑序。

拓扑排序可以：
- 判断有向图中是否有环；
- 生成一个拓扑序列。

注意：
- 一张图存在拓扑序，当且仅当它是有向无环图
- 拓扑序不一定唯一

## Kahn算法


**时间复杂度：** $O(n+m)$，其中 $n$ 为顶点数，$m$ 为边数。

设 `e[x]` 存储点 `x` 的出边终点，`tp` 存储拓扑序列，`din[x]` 存储点 `x` 的入度。

算法的核心是使用队列维护当前所有入度为 $0$ 的节点：

1. 将所有入度为 $0$ 的点压入队列 `q`。
2. 每次从 `q` 中取出一个点 `x`，将其放入 `tp`。
3. 枚举 `x` 的所有出边 $(x,y)$ 并将其删除，即令 `din[y]--`。若 `y` 的入度变为 $0$，则将 `y` 压入 `q`。
4. 重复步骤 2、3，直到队列为空。
5. 若 `tp` 中的元素个数等于 $n$，则 `tp` 是一个拓扑序；否则图中有环。

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

const int N = 1e5 + 5;
vector<int> e[N], tp;
int din[N];
int n, m;

bool toposort() {
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        if (din[i] == 0) q.push(i);
    }

    while (!q.empty()) {
        int x = q.front();
        q.pop();
        tp.push_back(x);
        for (int y : e[x]) {
            if (--din[y] == 0) q.push(y);
        }
    }
    return static_cast<int>(tp.size()) == n;
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        e[a].push_back(b);
        din[b]++;
    }

    if (!toposort()) {
        cout << -1;
    } else {
        for (int x : tp) cout << x << ' ';
    }
    return 0;
}
```

> [!note]
> Kahn 算法会修改 `din` 数组。如果后续仍需使用原始入度，应先复制一份。

## DFS算法

**时间复杂度：** $O(n+m)$。DFS 中每个点和每条边至多被访问一次，最后反转 `tp` 需要 $O(n)$。

设 `e[x]` 存储点 `x` 的出边终点，`tp` 存储拓扑序列，`c[x]` 存储点 `x` 的状态：

- `c[x] == 0`：尚未访问；
- `c[x] == -1`：正在当前 DFS 路径中；
- `c[x] == 1`：搜索完成，已加入 `tp`。

算法的核心是三色标记法。对每个节点进行 DFS：

1. 进入节点 `x` 时，将 `c[x]` 标记为 `-1`。
2. 枚举 `x` 的邻点 `y`。若 `c[y] == -1`，说明遇到了当前路径上的祖先节点，图中存在环；若 `c[y] == 0`，则继续递归搜索 `y`。
3. `x` 的所有邻点搜索完毕且未发现环后，将 `c[x]` 标记为 `1`，并把 `x` 加入 `tp`。
4. 因为节点是在其所有后继之后加入 `tp`，最后需要反转 `tp` 才能得到拓扑序。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

const int N = 1e5 + 5;
vector<int> e[N], tp;
int c[N];
int n, m;

bool dfs(int x) {
    c[x] = -1;

    for (int y : e[x]) {
        if (c[y] == -1) return false;
        if (c[y] == 0 && !dfs(y)) return false;
    }

    c[x] = 1;
    tp.push_back(x);
    return true;
}

bool toposort() {
    for (int i = 1; i <= n; i++) {
        if (c[i] == 0 && !dfs(i)) return false;
    }

    reverse(tp.begin(), tp.end());
    return true;
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        e[a].push_back(b);
    }

    if (!toposort()) {
        cout << -1;
    } else {
        for (int x : tp) cout << x << ' ';
    }
    return 0;
}
```

## 方法对比

| 方法 | 核心结构 | 判环依据 | 特点 |
| --- | --- | --- | --- |
| Kahn 算法 | 入度数组、队列 | 最终处理的节点数小于 $n$ | 过程直观，便于处理入度和分层问题 |
| DFS 算法 | 递归栈、三色标记 | 访问到当前路径中的节点 | 便于与其他 DFS 逻辑结合，但需注意递归深度 |
