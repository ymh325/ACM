> [!NOTE] 二分图
> 如果一张无向图的 $N$ 个节点可以分成 $A$,$B$ 两个不相交的非空集合，并且同一集合内的点之间没有边相连，那么称该无向图为二分图

例如：
![[Pasted image 20261103212039.png]]

(1,4) 为一个集合，(2,3,5)为一个集合。


**定理：二分图不存在奇环(长度为奇数的环)**
- 因为每一条边都是从一个集合走到另一个集合，只有走偶数次才可能回到同一个集合

**染色法**：
- 我们可以使用染色法来判定二分图。即尝试用两种颜色标记图中的节点，当一个点被标记后，所有与它相邻的节点应该标记与它相反的颜色，若标记过程产生冲突，则说明图中存在**奇环**。可以用DFS或BFS来实现。



变量定义：
- **颜色**`color[u]`: 存 `u` 点的颜色

算法流程：
1. color口初始化为0，被访问的点的颜色是1或2。
2. 进入u，对u点染色。
3. 枚举u的邻点v，
   (1）若v未访问，走进去，若返回有奇环，则一路返回有奇环。
   (2）若v已访问且v的颜色与u的颜色相同，则返回有奇环。
4. 枚举完u的邻点，没有发现奇环，则返回没有奇环。

> [!NOTE] 代码：$O(n+m)$
> 
```cpp
vector<int> e[N];

int dfs(int u, int c){
	color[u] = c;
	for(int v:e[u]){
		if(v==fat)continue;
		if(!color[v]){
			if(dfs(v,3-c))return 1;
		}
		else if(color[v] == c)return 1;
	}
	return 0;
}

signed main(){
	int n,m;
	for(int i=1;i<=m;i++){
		int u,v;cin>>u>>v;
		e[u].push_back(v);
		e[v].push_back(u);
	}
	int ok = 0;
	for(int i=1;i<=n;i++){
		if(!color[i]){
			if(dfs(i,1)){
				ok = 1;
				break;
			}
		}
	}
	if(ok)print("No");
	else print("Yes");
	return 0;
}

```
