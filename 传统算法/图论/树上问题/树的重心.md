# 树的重心

## 定义：

树的重心有如下**三种定义**，求出来的点是一样的 (同1个或2个):
1. 以某个节点为根时，最大子树的节点数最少，那么这个节点是重心
2. 以某个节点为根时，每颗子树的节点数不超过总节点数的一半，那么这个节点是重心 (dfs过程中容易直接求得重心)
3. 以某个节点为根时，所有节点都走向重心的总边数最少，那么这个节点是重心

> 前2种方法求重心最常用

补充性质：
- 一棵树最多有两个重心，如果有两个重心，那么两个重心一定相邻
- 如果树上**增加或者删除一个叶节点**，转移后的重心**最多移动一条边**
- 如果把**两棵树连起来**，那么新树的重心一定在**原来两棵树重心的路径上**
- 树上的边权如果都 $\geqslant 0$，不管边权怎么分布，所有节点都走向重心的总距离和最小




> [!warning] 有点权和没有点权，求重心是不一样的
> 要把点权也当成节点算上去
> 例如：`u` 的儿子有 `a`,`b`,`c`
> 则 `size[u] = size[a] + size[b] + size[c] + u的点权`
> 点权其实也可以理解为，一个点有几个分身，要全部考虑到




## 解决思路

​利用 `dfs` ，在搜索过程中顺带记录一些节点属性，从而求得树的重心任取一点 `u`，若以 `u` 为重心，则分为两类：
- **一类是u的子树**
- **一类是u上面的部分**

需要算出 `u` 的最大子树的结点数和 `u` 上面的部分的结点数，然后取二者的最大值即可。
- **size：** 记录 `u` 的最大子树的结点数；
- **sum：** 记录以 `u` 为根的子树的结点数；
- **n-sum：**  `u` 上面的部分的结点数;

`size` 、`sum` **可以在向下遍历返回时统计和累加**
`vis[u]`: 标记 `u` 这个点被搜索过

因为 `u` 是任取的一点，所以在遍历每个点时都会得到一个 `maxsub`，取最小值即可。

### 树的重心第一种求解方式

以某个节点为根时，最大子树的节点数最少，那么这个节点是重心

如果有2个重心，这里取编号最小的；
或者用个数组存储2个重心，根据题目要求来即可
```cpp
int best;
int siz[N];
int center;
int best = INF;
void dfs(int u,int fat){
    int maxsub = 0;
    int siz[u] = 1;
    for(int v:e[u]){
        if(v == fat)continue;
        dfs(v,u);
        siz[u] += siz[v];
        maxsub = max(maxsub,siz[v]);
    }
    maxsub = max(size,n - siz[u]);
	
	if(maxsub < best || (maxsub == beat && u < center)){
		best = maxsub;
		center = u;
	}	
}
```

### 树的重心第二种求解方式
以某个节点为根时，每颗子树的节点数不超过总节点数的一半，那么这个节点是重心

```cpp
int siz[N];
int cen[2],tp;
void dfs(int u,int fat){
    int maxsub = 0;
    siz[u] = 1;
    for(int v:e[u]){
        if(v == fat)continue;
        dfs(v,u);
        siz[u] += siz[v];
        maxsub = max(maxsub,siz[v]);
    }
    maxsub = max(maxsub,n - siz[u]);
	if(maxsub <= n/2){
		cen[tp++] = u;
	}
}
```

> 对于一个点 `x`，如果它**不是这颗树的重心**，那么**重心**一定在**以它为根的重儿子的子树**里面。
> 
> ​预处理一下各节点的重儿子，就可以**用倍增法快速向下跳**，判断那个点是重心。
