# 树的直径


## 定义

树上距离最远的两个点，形成的路径叫做树的直径

> [!NOTE] 树的直径两种求法:
> 1. 两次dfs的方式，适用于边权非负的树
> 优点：不仅能得到直径的长度，还能得到直径沿途所有点，等等很多信息
> 缺点：遍历两遍树
> >注意：也可用两次bfs实现，不过综合大部分教材、题解、模版、讨论贴来看，两次dfs的方式更常见
> 2. 树型dp的方式，适用于所有树
> 优点：遍历一遍树
> 缺点：只能得到直径的长度

> 直径**不一定**是唯一的，但可以证明：各直径的**中点**（不一定恰好是某个结点，可能在某条边的内部）是**唯一**的


如果树上的**边权都为正**，则有如下直径相关的结论：
1. 如果有多条直径，那么这些直径一定拥有共同的中间部分，可能是一个公共点或一段公共路径
2. 树上任意一点，相隔最远的点的集合，直径的两端点至少有一个在其中


**有两种求解思路：**

1. **两次DFS：**
	- **缺点**：仅适用于**正边权** ，因为此方法用到的一个引理只在正边权生效
	- **优点**：方便记录直径的路径。时间复杂度：$O(n)$
2. **树形DP：** 
	- **缺点：** 不方便记录直径的路径
	- **优点：** 适用于**正负边权**。时间复杂度：$O(n)$


## 解决思路 ① : 2次dfs

首先从任意节点 `x` 开始进行第一次 `DFS`，到达距离其最远的节点 `y`

然后再从 `y` 开始做第二次 `DFS` ，到达距离 `y` 最远的节点 `z`，则  `[y,z]` 即为树的直径。

> 对于此的证明可以去往 OI Wiki 网站学习 
>
> [OI Wiki]: https://oi-wiki.org/graph/tree-diameter/



令 `dep[]` 数组存储节点的深度，`mxd` 为最大路径 ，`[y,z]` 为直径两端

此代码的图存储方式为 **邻接表**
 
```cpp
void dfs(int u, int fat){
    for(auto ed:e[u]){
        int v = ed.v, w = ed.w;
        if(v == fat)continue;
        dep[v] = dep[u] + w;
        if(dep[v] > mxd) mxd = dep[v],y=v;
        dfs(v,u);
    }
}
```

## 解决思路 ② : 树形DP

利用 `dfs` ，在搜索过程中顺带记录一些节点属性，从而求得树的直径
任取一点 `u` ，从 `u` 点向下搜，返回时收集边的权值，记录 **两条路径**
- **d1：** 记录从 `u` 点往下走的最长路径的长度 
- **d2：** 记录从 `u` 点往下走的次长路径的长度
- **对于存储树的直径长度，2种方式**
  1. **`d[u] = d1 + d2`**。表示悬挂在 `u` 点上的最长路径的长度，遍历取最大值即可
  2. 可以用全局变量 `ans` ，实时更新。**`ans = max(ans,d1+d2)`**     

此代码的图存储方式为 **邻接表**

```cpp
int dfs(int u,int fat){  
     int d1 = 0,d2 = 0;  
     for(auto ed:e[u]){  
         int v = ed.v, w = ed.w;  
         if(v == fat)continue;  
         int d = dfs(v,u)+w;  
         if(d>d1)d2=d1,d1=d;  
         else if(d>d2) d2=d;  
     }  
     ans = max(ans,d1+d2);  
     return d1;  
 }
```
