### 字符串哈希


> [!NOTE] 字符串哈希
> 把不同的字符串映射成不同的整数

把字符串映射成一个 **P进制数字** 
对于一个长度为 `n` 的字符串 `s` ，定义哈希函数：
$$
h(S) = \sum^{n}_{i=1} s[i] × p^{n-i} (\bmod M)
$$

> [!example] 例如
> 字符串 `abc` ，哈希函数值为 $ap^2+bp^1+c$
> 即 $97×131^2 + 98×131^1+99$


# 哈希碰撞

> [!NOTE] 定义
> 如果两个字符串不一样，$Hash$ 函数值却一样，这样的现象称为 **哈希碰撞**

## 解决办法

巧妙设置 `p` 和 `M` 的值，保证 $p$ 和 $M$ 互质：
- $p$ 通常取质数 $131$ 或 $13331$ 
- $M$ 通常取大整数 $2^{64}$ ，把哈希值 `h` 定义为 `ull` ，超过则自动溢出，等价于取模。

# 实现

1. 求一个字符串的哈希值相当于**求前缀和**
	求一个字符串的子串的哈希值相当于**求区间和**
2. **前缀和** $h[i] = h[i - 1] \times p + s[i], \quad h[0] = 0$
   * $\text{A}$ ：    $A$ $\quad h[1] = 65$
   * $\text{AB}$ ：   $A \times p^1 + B, \quad h[2] = h[1] \times p + 66$
   * $\text{ABC}$ ：  $A \times p^2 + B \times p^1 + C, \quad h[3] = h[2] \times p + 67$
   * $\text{ABCD}$ ： $A \times p^3 + B \times p^2 + C \times p^1 + D$
   * $\text{ABCDE}$ ：$A \times p^4 + B \times p^3 + C \times p^2 + D \times p^1 + E$

1. **区间和** $h[l, r] = h[r] - h[l - 1] \times p^{r - l + 1}$
   例如，$DE = ABCDE - ABC \times p^2 = D \times p^1 + E$
   即 $h[4, 5] = h[5] - h[3] \times p^2$

2. 计算前缀和，时间复杂度：$O(n)$
   查询区间和，时间复杂度：$O(1)$
```cpp
const ull unsigned long long 
const int P = 131;
// p[i] = p^i, h[i] = s[1~i]的hash值
ull p[N],h[N];
// 预处理 hash函数 的前缀和
void init(){
    p[0]=1,h[0]=0;
    for(int i=1;i<=n;i++){
        p[i]=p[i-1]*p;
        h[i]=h[i-1]*p+s[i];
    }
}
// 获取s[l~r]的hash值
ull get(int l,int r){
    return h[r]-h[l-1]*p[r-l+1];
}

bool is_same(int l1,int r1,int l2,int r2){
    return get(l1,r1)==get(l2,r2);
}
```
