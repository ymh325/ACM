> [!example] 对于 [[KMP算法|KMP]] 和 [[AC自动机]]

|       |     KMP     |          AC自动机           |
| :---: | :---------: | :----------------------: |
|  匹配   | **单模式**匹配算法 |       **多模式**匹配算法        |
|  形态   |   链上构造自动机   |       Trie树上构造自动机        |
| 数据维护  |     回跳边     | 回跳边 ne[]，树边，转移边 `ch[][]` |
| 算法流程  | 双指针建边，双指针匹配 |       BFS建边，双指针匹配        |
| 时间复杂度 |   O(n+m)    |         O(26n+m)         |
