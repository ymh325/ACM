# 马拉车

> Manacher 


> [!done] 简介
> 可以在 $O(n)$ 的时间内求出一个字符串中的**最长回文串**


算法过程：
- 改造字符串
	
- 回文半径 `d[i]`
	
- 加速盒子 `[l,r]`

## 改造字符串

在字符串之间和串的两端插入 `#` ，改造后，都变成 **奇回文串** ，方便统一处理。

- 奇回文串 `aba`   ->  `#a#b#a#` 
- 偶回文串 `abba` -> `#a#b#b#a#`  

令 `s[0] = '$'` (也可以是其他字符)，把 $0$ 的位置空出来，方便写代码；

>有多种实现方式，如下仅供参考

## 回文半径

> [!abstract] 定义
> 以 $i$ 为中心的 **最长回文串** 的长度的一半，叫回文半径

![[马拉车_回文半径.png|418]]


## 加速盒子 


> [!tip] Title
> 算法过程中，**维护右端点最靠右的最长回文串**，利用盒子，借助之前的状态来加速计算新的状态。盒内 `d[i]` 可以利用 **对称点** 的 d 值转移，盒外暴力

![[马拉车_回文半径.png|418]]


算法流程：
计算完前 $i-1$ 个 $d[i]$ ，维护盒子 $[l,r]$ ；
1. 如果 $i \leq r$ （在盒内），$i$ 的<font color="#ff0000">对称点</font>为 $r-i+l$ 
	- 若 $d[r-i+l] < r-i+1$ ，则 $d[i] = d[r-i+l]$ 。
	- 若 $d[r-i+l] \geq r-i+1$ ，则令 $d[i] = r-i+1$ ，从 $r+1$ 往后暴力枚举。  
2. 如果 $i > r$ （在盒外），则从 $i$ 开始暴力枚举。
3. 求出 $d[i]$ 后，如果 $i + d[i] - 1 > r$ ，则更新盒子 $l = i-d[i]+1$ ，$r = i+d[i]-1$。

![[马拉车_图示.png]]

### 代码
```cpp
void get_d(string s,int n){
	d[1] = 1;
	for(int i=2,r=1,l;i<=n;i++){
		if(i<=r) d[i] = min(d[r-i+l],r-i+1);
		while(s[i-d[i]] == s[i+d[i]]) d[i]++;
		if(i + d[i]-1 > r)l = i-d[i] + 1,r = i+d[i]-1;
	}
}
```

> [!info] 细节
> 原串的最长回文串 = 新串的最大半径-1 


> [!question] while  复杂度分析
>对于 while 循坏 ，如果条件成立，$d$++ ，即盒子的右端点 $r$ 就会后移动若干位，而 $r\leq n$ ，故 $r$ 右移总步数不会超过 $n$ 。所以时间复杂度为 $O(n)$。
