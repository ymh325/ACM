# AC自动机


> [!done] <font color="#00b050">自动AC机</font>
> **一种多模式匹配算法**。给定 $n$ 个模式串和一个主串，查找多少个模式串在主串中出现过


💡**AC自动机** = [[字典树]] + [[KMP算法|KMP]]

AC自动机在 $Trie$ 树上添加 **Fail 指针**，该指针和 $KMP$ 中的 **Fail 指针**  功能类似


**步骤**：

1. **构造Trie树**
   我们先用 $n$ 个模式串构造一颗 $Trie$
   $Trie$ 中的一个 **节点** 表示一个从根到当前节点的 **字符串**
   根节点表示空串，节点 ⑤ 表示 “s” ，节点 ⑥ 表示 “sh”，节点 ⑦ 表示“she”。
> 如果节点是个模式串，则打个标记。例如，$cnt[7] = 1$。

2. **构造AC自动机**

   在 $Trie$ 上构建两类边：**回跳边** 和 **转移边**

3. **扫描主串匹配**



## 构造Trie树

```cpp
int ch[N][26],cnt[N],idx;
int ne[N];
void insert(char *s){ //建树
    int p = 0;
    for(int i=0;s[i];i++){
        int j=s[i]-'a';
        if(!ch[p][j])ch[p][j]=++idx;
        p=ch[p][j];
    }
    cnt[p]++;
}
```


## 回跳边和转移边

- <font color="#00b050">回跳边</font>：用<font color="#00b050">绿色</font>表示
- <font color="#ff0000">转移边</font>：用<font color="#ff0000">红色</font>表示

> [!example] 回跳边的指向关系
> 
> 设节点 `v` 的父节点为 `u`，且 `u` 通过字符 `i` 的树边到达 `v`。
> - 记 `ne[v]` 为节点 `v` 的回跳边终点，则有：
> 
> ```
> ne[v] = ch[ne[u]][i]
> ```
> 

因此，`v`、`u`、`ne[u]` 和 `ch[ne[u]][i]` 四个节点构成图中的四边形关系。

回跳边始终指向当前节点对应字符串的**最长、且存在于 Trie 中的真后缀**，所以 `ne[v]` 就是 `v` 的最长可匹配后缀所对应的节点。这里的“后缀”不要求本身是模式串，只要它是 Trie 中某个节点表示的字符串即可。

![[回跳边.png]]



> [!NOTE] 转移边的指向关系
> 
> 对于节点 `u` 和字符 `i`，`ch[u][i]` 表示从 `u` 沿字符 `i` 出发的转移边终点。
> 
> **若 `ch[u][i]` 为空**，则沿着 `u` 的回跳边到达 `ne[u]`，再沿字符 `i` 进行转移，并将得到的节点作为 `ch[u][i]`：
> 
> ```
> ch[u][i] = ch[ne[u]][i]
> ```
> 

构造完成后，每个 `ch[u][i]` 都有定义。转移边终点表示：在当前状态对应的字符串后追加字符 `i` 后，得到的**最长可匹配后缀**（即 Trie 中存在的最长后缀）。如果当前节点没有字符 `i` 的树边，就沿回跳边继续寻找；BFS 建造时，这个过程已经被压缩到一次 `ch[ne[u]][i]` 查询中。

## 构造AC自动机

> [!NOTE] **用BFS构造AC自动机**
> 
> 初始化把根节点的儿子们入队。
> 只要队不空，节点 $u$ 出队，
> 枚举 $u$ 的 $26$ 个 儿子，
> 
> 1. 若 **儿子存在**，则爹帮儿子建 **回跳边**，并把儿子入队。
> 2. 若 **儿子不存在** ，则爹自建 **转移边**
> 

![](回跳边和和转移边.png)


### CODE $O(26n)$

$n$ 为模式串总长度

```cpp
void build(){
    queue<int> q;
    for(int i=0;i<26;i++)
    	if(ch[0][i])q.push(ch[0][i]);
    
    while(q.size()){
        int u=q.front();q.pop();
        for(int i=0;i<26;i++){
            int v=ch[u][i];
            if(v)ne[v]=ch[ne[u]][i],q.push(v);
            else ch[u][i]=ch[ne[u]][i];
        }
    }
}
```

## 查找出现的不同单词的数量

扫描主串，依次取出字符 `s[k]`,

1. `i` 指针走主串对应的节点，沿着**树边**或**转移边**走，保证不回退
2. `j` 指针沿着**回跳边**搜索模式串，每次从当前节点
   走到根节点，把当前节点中的所有后缀模式串
   一网打尽，保证不漏解。

3. 扫描完主串，返回答案。
   算法一边走串，一边把当前串的所有后缀串搜出来，实在是强。

> 真是天雷滚滚，秒不可言啊！


> [!example] Title
> 

m 为主串长度，n 为模式串的总长度
这个查询版本是**查询主串中出现了几种模式串**

比如：
- 主串为 `abcdcd`
- 模式串为 `ab`、`cd`、`ac`

那么 `query()` 返回的结果为 2，出现的模式串为 `ab`、`cd`

```cpp
int query(char *s){
    int ans=0;
    for(int k=0,i=0;s[k];k++){
        i = ch[i][s[k]-'a'];
        for(int j=i;j&&~cnt[j];j=ne[j])
            ans+=cnt[j],cnt[j]=-1;// 这里将会清除标记,这样的话~cnt[j]=0
    }
    return ans;
}
```


## 回跳边和转移边的再理解

> [!example] 回跳边

主串 `s = "abcdefg"` 为例：
模式串 `bcde`、`cde` 、`de`

扫描到字符 `e` 时，当前状态停在 `bcde`。
随后利用 `j` 回跳到 `cde`，再到 `de`:
- 相当于依次枚举当前匹配串的后缀。
- 既然 `bcde` 已经匹配，那么这些后缀也一定出现在当前位置；
- 只需检查它们是否为模式串。

```cpp
for(int j=i;j&&~cnt[j];j=ne[j])
    ans+=cnt[j],cnt[j]=-1;// 这里将会清除标记,这样的话~cnt[j]=0
```

这个代码版本会把访问过的 `cnt[j]` 标记为 `-1`，因此同一个模式串只会计入答案一次。


> [!example] 转移边

模式串 `ab`、`bc`，扫描主串 `s = "abc"`：

读完 `ab` 后，当前节点是 `ab`。读入 `c` 时，`ab` 没有字符 `c` 的树边，于是沿回跳边到 `b`；节点 `b` 有字符 `c` 的树边，最终转移到 `bc`。

因此，转移边把“回跳后再尝试字符”的过程预先算好。扫描主串时只需执行：

```cpp
i = ch[i][s[k] - 'a'];
```

指针不会回退，且始终停在当前已读前缀的最长可匹配后缀节点。

> 相当于给原来的匹配字符串续命
