# 枚举二进制集合的所有子集


```cpp
int mask = "二进制集合";
for(int j=mask ; j ; j = (j-1) & mask ){
	
}
```


> [!example] 例如
> 

`int mask = 0b1011 ;`

| **步骤**    | **当前 j (十进制)** | **当前 j (二进制)** | **执行 j - 1** | **与 mask (10112​) 位与: (j - 1) & mask** | **下一步的 j (二进制)** |
| --------- | -------------- | -------------- | ------------ | -------------------------------------- | ---------------- |
| **初始**    | 11             | `1011`         | -            | -                                      | -                |
| **第 1 次** | 11             | `1011`         | `1010`       | `1010 & 1011 = 1010` (10)              | `1010`           |
| **第 2 次** | 10             | `1010`         | `1001`       | `1001 & 1011 = 1001` (9)               | `1001`           |
| **第 3 次** | 9              | `1001`         | `1000`       | `1000 & 1011 = 1000` (8)               | `1000`           |
| **第 4 次** | 8              | `1000`         | `0111`       | `0111 & 1011 = 0011` (3)               | `0011`           |
| **第 5 次** | 3              | `0011`         | `0010`       | `0010 & 1011 = 0010` (2)               | `0010`           |
| **第 6 次** | 2              | `0010`         | `0001`       | `0001 & 1011 = 0001` (1)               | `0001`           |
| **第 7 次** | 1              | `0001`         | `0000`       | `0000 & 1011 = 0000` (0)               | `0000`           |

# 旅行商问题（TSP）

给定 `n` 个点和两点间距离，从 `0` 号点出发，访问每个点恰好一次后回到 `0` 号点，求最短路程。

## 状态定义

```cpp
dp[mask][i] = 已访问集合为 mask，且当前位于 i 号点时的最短路程
```

其中 `i` 必须属于 `mask`。初始状态为 `dp[1][0] = 0`，因为只访问了起点 `0`。

## 状态转移

从当前点 `i` 前往还没有访问过的点 `j`：

```cpp
nextMask = mask | (1 << j);
dp[nextMask][j] = min(dp[nextMask][j], dp[mask][i] + dis[i][j]);
```

全部点访问完后，再加上回到起点的距离：

```cpp
answer = min(dp[(1 << n) - 1][i] + dis[i][0]);
```





# 常见变形

- **计数型**：`dp[mask]` 表示组成该集合的方案数，转移时做加法。
- **存在性**：`dp[mask]` 表示状态是否可达，转移时做逻辑或。
- **带最后位置**：例如 TSP 使用 `dp[mask][i]`。
- **集合拆分**：需要枚举子集 `sub`，常见于集合划分和合并问题。
- **轮廓线 DP**：把网格某一行（或一列）的占用情况压成二进制状态，是状压 DP 在网格上的应用。
