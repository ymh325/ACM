# ICPC 铜牌训练路线

目标按 **ICPC 亚洲区域赛铜牌的备赛需求**理解：基础题做得快，中档题能独立建模，三人能在限时内合理选题、实现和查错。不同年份、站点的铜牌线差异很大，**不存在统一的“做几题拿铜”或“CF 多少分等于铜牌”**；下面的分层是训练安排，不是官方难度认证，也不保证刷完拿牌。

本题单共 **87 道不重复题目**：12 道基础诊断、48 道核心主线、12 道进阶补强、15 道混合盲测。默认你已会 C++、STL 和基本复杂度分析；不需要先学完所有高级算法。

## 怎么刷

1. **先诊断。** 做基础区 A01—A12。多数题能在 20—35 分钟独立通过，就直接进入主线；否则先补排序、前缀和、双指针、枚举和 STL。
2. **主线优先。** B—G 共 48 题是主要投入方向。每个专题按表内顺序推进，同时交替训练不同专题，不必连续刷完一个专题再碰别的。
3. **补强按短板选。** H 区 12 题用于扩展可做题范围；主线尚不稳定时，先回头重做错题。高级模板数量不是首要目标。
4. **每周一次混合训练。** 用盲测或没做过的比赛，隐藏标签和题解。专题中顺利 AC 的题，隔一周打乱顺序再做，检验是否真的掌握。

建议节奏：每周 6—8 道新题、一次限时训练、一次复盘。可先用 8—12 周完成基础与主线，再根据队伍情况补强；这是安排参考，不是水平提升保证。

| 阶段 | 重点 | 建议产出 |
| --- | --- | --- |
| 第 1—2 周 | A 区诊断，B/C 区思维、二分与计数 | 写清楚贪心依据、二分单调性、计数对象 |
| 第 3—4 周 | D 区 DP，穿插 B/C 未完成题 | 能自己定义状态，解释转移顺序与复杂度 |
| 第 5—6 周 | E 区图论，F 区数据结构与树 | 先建模，再决定 BFS、Dijkstra、并查集或区间结构 |
| 第 7—8 周 | G 区数论与字符串，重做主线错题 | 掌握溢出、取模、逆元条件、字符串边界 |
| 第 9—12 周 | H 区选做，混合训练与整场比赛 | 找出稳定得分点，练选题、协作和补题 |

## 单题训练规则

- 基础题先独立思考 20—35 分钟；主线题 45—75 分钟；补强题 60—100 分钟。时间是训练预算，可按基础调整。
- 卡住先写：暴力算法、瓶颈、数据范围允许的复杂度、可能利用的性质。仍无进展，再看一条提示，而不是直接抄完整代码。
- 看过题解后关掉页面，自己写出证明或状态定义，再实现。记录为“补题 AC”，不要记成“独立 AC”。
- 用题解做出的题，在 2—3 天后和 1—2 周后各独立重做一次；若仍依赖提示，就保留在错题清单。
- AC 前检查：多测清空、整数溢出、空集合、重复值、下标边界、递归深度，以及最坏复杂度。可写暴力对拍的题，优先用小数据验证。

## 怎样判断练得够不够

以下是**本题单的训练验收建议**，不是奖牌线：

- 基础区的常见模型能独立完成，少在实现上反复 WA。
- 主线中至少约 70% 能在隐藏标签的情况下独立解决；剩余题能说清卡在建模、知识还是实现。
- 三组盲测中至少两组在 180 分钟内独立通过 4 题，并完成所有补题。做过原题就换未见题，熟题成绩不计入验收。
- 能解释正确性和复杂度，能识别“需要什么算法”，而不是只有看到专题名才会做。

**最后仍要做三人、单机、5 小时的整场训练。** 本题单不能代替区域赛长题面、读题取舍和协作压力。选择未做过、能找到官方题面和榜单的往届区域赛，对照该场实际铜牌边界复盘；注意榜单中的正式队、打星队和参赛资格差异。不要直接套用其他站点的过题数。

队内可由不同人偏重图论/数据结构、DP、数学/字符串，但三个人都应能处理基础思维和常见模型。整场训练中约定读题分工、上机顺序和长时间卡题时的换人规则。
