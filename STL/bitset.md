# Bitset

`bitset` 是 C++ STL 中用来存储固定长度二进制位的容器；

- 头文件：
```cpp
#include <bitset>
```


> [!question] 什么时候要考虑用bitset?
> 当需要二进制数处理，且二进制数的长度超出了 64 位，可用bitset处理；

# 基础操作
## 创建


- 定义： `bitset<N> num`，$N$ 为二进制位数；

- 默认创建时，所有位都是 `0`。
```cpp
bitset<8> a;        // 00000000
bitset<8> b(13);    // 00001101
```

- 字符串创建：
```cpp
bitset<8> a(string("10110010")); // 10110010
bitset<8> b(string("0110"));     // 00000110, 位数不足则在左边补齐 
```

>注意：字符串的左边是高位，右边是低位。

```cpp
bitset<8> b(string("00001101"));

cout << b[0] << '\n'; // 1，最低位
cout << b[2] << '\n'; // 1
cout << b[7] << '\n'; // 0，最高位
```

`bitset` 的下标从 `0` 开始，`b[0]` 表示最低位，也就是输出字符串最右边那一位。

## 访问与修改

### 单点访问

```cpp
b[i]
```

访问第 `i` 位，返回这一位是 `0` 还是 `1`。

```cpp
bitset<8> b(string("00001101"));

cout << b[0] << '\n'; // 1
cout << b[1] << '\n'; // 0
```

也可以直接修改：

```cpp
b[1] = 1;
b[2] = 0;
```

### 设置为 1

- `b.set()` , 把所有位都变成 `1`。
```cpp
bitset<8> b;
b.set(); // 11111111
```

- `b.set(i)` ，把第 `i` 位设置为 $1$
```cpp
bitset<8> b;
b.set(3); // 00001000
```

- `b.set(i,val)` ，把第 `i` 位设置为 $1$ 或 $0$ ；
```cpp
bitset<8> b;
b.set(3,1); // 00001000
cout<<b<<'\n';

b.set(2,1); // 00001100
cout<<b<<'\n';

b.set(2,0); // 00001000
cout<<b<<'\n';
```
 
### 清零

- `b.reset()` ，把所有位都变成 `0`。
```cpp
bitset<8> b(string("11110000"));
b.reset(); // 00000000
```

- `b.reset(i)`， 只清零第 `i` 位：
```cpp
bitset<8> b(string("11111111"));
b.reset(2); // 11111011
```

### 翻转

-  `b.flip()` ，把所有位翻转，`0` 变 `1`，`1` 变 `0`。
```cpp
bitset<8> b(string("10101010"));
b.flip(); // 01010101
```

- `b.flip(i)`，翻转第 `i` 位；
```cpp
bitset<8> b(string("00000000"));
b.flip(2); // 00000100
```

### 判断是否为1

```cpp
b.test(pos);
```

判断第 `pos` 位是否为 `1`。

```cpp
if (b.test(3)) {
    cout << "第 3 位是 1\n";
}
```

`test(pos)` 会做越界检查，如果 `pos >= b.size()`，会抛出异常；而 `b[pos]` 不做越界检查。

## 状态判断

### 是否存在一

```cpp
b.any();
```

只要有一位是 `1`，就返回 `true`。

```cpp
if (b.any()) {
    cout << "至少有一个 1\n";
}
```

### 是否全是一

```cpp
b.all();
```

所有位都是 `1` 时返回 `true`。

```cpp
if (b.all()) {
    cout << "全是 1\n";
}
```

### 是否全是零

```cpp
b.none();
```

所有位都是 `0` 时返回 `true`。

```cpp
if (b.none()) {
    cout << "全是 0\n";
}
```

### 统计一的数量

```cpp
b.count();
```

返回 `1` 的个数。

```cpp
bitset<8> b(string("10101100"));
cout << b.count() << '\n'; // 4
```

### 获取大小

```cpp
b.size();
```

返回 `bitset` 的总位数。

```cpp
bitset<100> b;
cout << b.size() << '\n'; // 100
```

# 位运算

`bitset` 支持常见的位运算：


| 操作        |    含义    |     |
| --------- | :------: | --- |
| `a & b`   |    与     |     |
| a \| b    |    或     |     |
| `a ^ b`   |    异或    |     |
| `~a`      |   按位取反   |     |
| `a << k`  | 左移 `k` 位 |     |
| `a >> k`  | 右移 `k` 位 |     |
| `a &= b`  |  按位与后赋值  |     |
| a \|= b   |  按位或后赋值  |     |
| `a ^= b`  | 按位异或后赋值  |     |
| `a <<= k` |  左移后赋值   |     |
| `a >>= k` |  右移后赋值   |     |

示例：

```cpp
bitset<8> a(string("10110000"));
bitset<8> b(string("01101000"));

cout << (a & b) << '\n'; // 00100000
cout << (a | b) << '\n'; // 11111000
cout << (a ^ b) << '\n'; // 11011000
cout << (~a) << '\n';    // 01001111
```

移位示例：

```cpp
bitset<8> b(string("00001101"));

cout << (b << 2) << '\n'; // 00110100
cout << (b >> 2) << '\n'; // 00000011
```

左移相当于让原来的第 `i` 位移动到第 `i + k` 位；右移相当于让原来的第 `i` 位移动到第 `i - k` 位。

# 转换

## 转成字符串

```cpp
b.to_string();
```

返回一个由 `0` 和 `1` 组成的字符串。

```cpp
bitset<8> b(13);
string s = b.to_string();
cout << s << '\n'; // 00001101
```

## 转成整数

```cpp
b.to_ulong();
b.to_ullong();
```

分别转成 `unsigned long` 和 `unsigned long long`。

```cpp
bitset<8> b(string("00001101"));

cout << b.to_ulong() << '\n';  // 13
cout << b.to_ullong() << '\n'; // 13
```

如果 `bitset` 表示的数超过了目标整数类型能表示的范围，会抛出异常。

# 常见用法

## 集合操作

可以把第 `i` 位看成元素 `i` 是否存在。

```cpp
bitset<1000> A, B;

A.set(1);
A.set(3);
A.set(5);

B.set(3);
B.set(4);
B.set(5);
```

交集：

```cpp
bitset<1000> C = A & B;
```

并集：

```cpp
bitset<1000> C = A | B;
```

判断是否有交集：

```cpp
if ((A & B).any()) {
    cout << "有公共元素\n";
}
```

统计交集大小：

```cpp
cout << (A & B).count() << '\n';
```

## 可达性 DP

`bitset` 很适合优化“能不能凑出某个值”的问题。

比如有若干物品重量 `w`，判断哪些重量和可以被凑出来：

```cpp
bitset<10001> dp;
dp[0] = 1;

for (int w : a) {
    dp |= (dp << w);
}
```

含义：

- `dp[i] = 1` 表示当前可以凑出重量 `i`
- `dp << w` 表示在原来所有可达重量的基础上，再加上当前物品重量 `w`
- `dp |= (dp << w)` 表示把新可达的状态合并进去

例如原来可以凑出 `0, 3, 5`，当前物品重量是 `2`，那么左移后可以凑出 `2, 5, 7`。

## 图的邻接关系

如果图的点数不太大，可以用 `bitset` 存每个点的邻接点。

```cpp
const int N = 2000;
bitset<N> g[N];

g[u].set(v);
g[v].set(u);
```

判断两个点是否有公共邻居：

```cpp
if ((g[u] & g[v]).any()) {
    cout << "有公共邻居\n";
}
```

统计公共邻居数量：

```cpp
int cnt = (g[u] & g[v]).count();
```

这类写法在图论题里非常常见，可以把枚举邻居的复杂度压低很多。

# 注意事项

- `bitset<N>` 的大小 `N` 必须是编译期常量。
- `bitset` 不能动态改变大小，如果需要运行时决定大小，可以考虑 `vector<bitset<M>>` 或其他写法。
- `b[0]` 是最低位，也就是输出字符串的最右边一位。
- `cout << b` 输出时，从高位到低位输出。
- `set()`、`reset()`、`flip()` 不传参数时操作所有位，传参数时操作指定位置。
- `count()`、`any()`、`none()`、`all()` 是竞赛里最常用的判断函数。
